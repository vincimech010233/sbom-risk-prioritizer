# Acceptance criteria

1. Exact fixture ranks and score intervals match documented values; unassessed remains unknown.
2. Reject non-synthetic inputs, orphan/duplicate refs, out-of-range severity, missing provenance and unsupported fields.
3. Record-order permutation leaves output unchanged.
4. Rust lint/format/tests and Python Markdown regression/escaping tests pass.
5. Offline scope, evidence limits and publication checks are explicit.

All criteria must be executed locally or explicitly listed as unresolved. Reviewer acceptance is bounded by this profile.
